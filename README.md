🌤️ Weather Analytics Dashboard

An interactive and responsive Weather Analytics Dashboard built using HTML, CSS, JavaScript, Open-Meteo API, and Chart.js.

The dashboard provides real-time weather information for any searched location along with 7-day forecasts, hourly precipitation analysis, temperature trends, and sunrise/sunset visualization.

📌 Project Overview

The Weather Analytics Dashboard is designed to present weather information in a clean and user-friendly dashboard format.

Users can search for a city or location and view:

🌡️ Current temperature
🌤️ Current weather conditions
💧 Humidity
💨 Wind speed
⏱️ Atmospheric pressure
👁️ Visibility
📅 7-day weather forecast
🌧️ Hourly precipitation levels
📈 Hourly temperature trends
🌅 Sunrise and sunset timings
☀️ Daylight duration
🌙 Night duration
📍 Latitude and longitude
🕒 Location-based time zone
📆 Current calendar
🎯 Objectives

The main objectives of this project are to:

Build an interactive weather dashboard.
Retrieve real-time weather data using an API.
Visualize weather data using charts.
Provide hourly and daily weather analysis.
Create a responsive and modern user interface.
Demonstrate the practical use of JavaScript and API integration.
Present weather information in an easy-to-understand format.
✨ Features
🔎 Location Search

Users can enter a city or place in the search bar.

The application automatically finds the location using the Open-Meteo Geocoding API.

🌡️ Current Weather

The dashboard displays:

Current temperature
Feels-like temperature
Weather condition
Humidity
Wind speed
Atmospheric pressure
Visibility
📅 7-Day Forecast

The dashboard provides a seven-day forecast including:

Day
Date
Weather condition
Weather icon
Maximum temperature
Minimum temperature
🌧️ Precipitation Analysis

An interactive bar chart displays the precipitation level for each hour of the current day.

Unit: millimetres (mm)

This makes it easier to identify periods with higher precipitation.

🌡️ Temperature Trend

A line chart displays the hourly temperature trend throughout the day.

Unit: °C

This provides a visual representation of how temperature changes during the day.

🌅 Sunrise & Sunset Timeline

The dashboard includes a visual timeline showing:

Sunrise
Sunset
Daylight period
Night period
Total daylight duration
Total night duration
📍 Location Information

The dashboard also displays:

Latitude
Longitude
Time zone
Weather code
📆 Dynamic Calendar

A calendar is included in the right-side panel with the current date highlighted.

📱 Responsive Design

The dashboard is designed to work across:

💻 Desktop
💻 Laptop
📱 Mobile
📟 Tablet

The layout automatically adjusts according to screen size.
